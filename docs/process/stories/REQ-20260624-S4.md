# REQ-20260624-S4: Project Layer Browser (tree + preview)

## Description

As a developer using the Kuraka Control Plane, I want to browse a registered
project's `.claude/project/` directory and preview individual files, so that I
can inspect the project's specialization layer without leaving the dashboard.

**Smoke flow:** open `/projects/kuraka-control` → click "Project Layer" tab →
tree loads showing `conventions/`, `review-checks/`, etc. → click
`conventions/typescript.md` → preview pane shows file content on the right.

**Split: S4a (backend) must land first; S4b (frontend) may begin once the
contract is frozen (Phase 3). Implement sequentially, `make test` between them
per T6.**

## Story S4a — Backend: layer tree-walk + contained file-read + 2 endpoints

### Acceptance Criteria — Backend-Tree

- [ ] **B1.** `GET /api/projects/:name/layer` returns `200 LayerTreeResponse`
      when `<project.path>/.claude/project/` exists; `has_layer: true`,
      `root_rel: ".claude/project"`, `nodes` populated.
- [ ] **B2.** `has_layer` is computed from a **live `fs.stat`** of the layer
      directory — the registry `has_project_layer` flag is NEVER used for this
      field (flag-drift confirmed: `bol-cert-no-deudor` flag=false, dir present).
- [ ] **B3.** When the layer directory is absent (project registered but no
      `.claude/project/`), the endpoint returns `200` with `has_layer: false,
      nodes: [], empty: true` — never 404 or 500.
- [ ] **B4.** When the project path itself is missing on disk, the endpoint
      degrades to `has_layer: false` (200) — not a 500.
- [ ] **B5.** Tree walk: **dirs-first then files** within each level, each group
      sorted alphabetically by name. Dotfiles (names starting with `.`) are
      **included** (`.gitkeep` is visible; the `.claude/project/` root itself
      is walked, not hidden).
- [ ] **B6.** Walk is bounded: `MAX_DEPTH = 8`, `MAX_ENTRIES = 2000`. Exceeding
      either cap sets `truncated: true` and returns the partial tree — never hangs.
      Constants `MAX_DEPTH` and `MAX_ENTRIES` are module-level constants
      (not magic numbers inside the function).
- [ ] **B7.** Symlinked directories are **not followed** during the walk;
      symlinked files appear as file entries (re-validated on read via realpath).
- [ ] **B8.** Every `LayerNode` of type `"file"` carries `size_bytes`
      (from `stat.size`). Every `LayerNode` of type `"dir"` has `children`
      (array, may be empty); files have no `children` key.
- [ ] **B9.** `:name` not in the registry → `404 NOT_FOUND`. `:name` containing
      `/` or `\` → `404 NOT_FOUND` (mirrors existing guard in `routes/projects.ts`).

### Acceptance Criteria — Backend-FileRead-Containment (LL-011 — EXACT mechanism)

- [ ] **B10.** `GET /api/projects/:name/layer/file?path=<rel>` resolves using
      the exact two-stage algorithm below. Any violation of a step → `403
      PATH_FORBIDDEN`; the file is **never read**:

      ```
      Step 1 (pre-resolve rejections — no fs touch):
        if (!rel || rel === "")                          → 400 BAD_REQUEST
        if (path.isAbsolute(rel))                        → 403 PATH_FORBIDDEN
        if (rel.includes("\0"))                          → 403 PATH_FORBIDDEN
        const normalized = path.normalize(rel)
        if (normalized.startsWith(".."))                 → 403 PATH_FORBIDDEN
        if (normalized.split(path.sep).includes(".."))  → 403 PATH_FORBIDDEN

      Step 2 (resolve):
        const root      = path.resolve(projectPath, ".claude/project")
        const candidate = path.resolve(root, rel)

      Step 3 (realpath both sides — resolves symlinks):
        const realRoot   = await fs.realpath(root)
        const realTarget = await fs.realpath(candidate)
          — if realpath throws ENOENT → 404 NOT_FOUND
          — if realpath throws EACCES → 403 PATH_FORBIDDEN

      Step 4 (containment check — exact boundary):
        if (realTarget !== realRoot &&
            !realTarget.startsWith(realRoot + path.sep)) → 403 PATH_FORBIDDEN

      Step 5 (must be a regular file):
        const stat = await fs.stat(realTarget)
        if (!stat.isFile())                              → 403 PATH_FORBIDDEN
      ```

- [ ] **B11.** `403` response carries only `detail: { rel }` — the resolved
      absolute path is **never** included in the response body (no path leak).
- [ ] **B12.** `path` query param absent or empty → `400 BAD_REQUEST` (before
      any fs touch).
- [ ] **B13.** File exceeds `LAYER_FILE_MAX_BYTES = 1_048_576` (1 MiB): stat
      before read; `too_large: true, content: null` — file is never read into
      memory. `LAYER_FILE_MAX_BYTES` is a module-level constant.
- [ ] **B14.** Binary detection: read file into a `Buffer`; scan the first
      `BINARY_SAMPLE_BYTES = 8192` bytes for a NUL byte (`0x00`); if found →
      `binary: true, content: null`. `BINARY_SAMPLE_BYTES` is a module-level
      constant.
- [ ] **B15.** Empty file (size = 0): `content: ""`, `binary: false`,
      `too_large: false` — empty is not an error (`.gitkeep` precedent).
- [ ] **B16.** Valid file that is text, within size limit: `content` is the UTF-8
      string; `binary: false`, `too_large: false`.
- [ ] **B17.** File not found after containment passes (ENOENT at read) →
      `404 NOT_FOUND` with `detail: { rel }`.
- [ ] **B18.** `LayerFileResponse.rel_path` echoes the **validated** `rel` value
      (not the resolved absolute path).
- [ ] **B19.** `layerReader.ts` calls **no** `fs.writeFile`, `fs.mkdir`, `fs.rm`,
      or `spawn`. Read-only; does not touch the WriteFirewall.

### Acceptance Criteria — Contract

- [ ] **C1.** `packages/contracts/src/index.ts` exports the following schemas
      (exact zod — frozen seam):

      ```typescript
      // Recursive node — z.lazy required for self-reference
      export const LayerNode: z.ZodType<LayerNodeShape> = z.lazy(() =>
        z.object({
          name:       z.string(),
          type:       z.enum(["dir", "file"]),
          rel_path:   z.string(),
          size_bytes: z.number().nullable(),
          children:   z.array(LayerNode).optional(),
        })
      );
      export type LayerNodeShape = {
        name:       string;
        type:       "dir" | "file";
        rel_path:   string;
        size_bytes: number | null;
        children?:  LayerNodeShape[];
      };

      export const LayerTreeResponse = z.object({
        has_layer:  z.boolean(),
        root_rel:   z.string(),
        nodes:      z.array(LayerNode),
        empty:      z.boolean(),
        truncated:  z.boolean(),
      });
      export type LayerTreeResponse = z.infer<typeof LayerTreeResponse>;

      export const LayerFileResponse = z.object({
        rel_path:   z.string(),
        name:       z.string(),
        content:    z.string().nullable(),
        size_bytes: z.number(),
        truncated:  z.boolean(),
        too_large:  z.boolean(),
        binary:     z.boolean(),
      });
      export type LayerFileResponse = z.infer<typeof LayerFileResponse>;
      ```

- [ ] **C2.** Error codes used: `NOT_FOUND`, `PATH_FORBIDDEN`, `BAD_REQUEST`,
      `VAULT_UNREADABLE` — uniform `ApiError` envelope (existing shape, no new
      envelope schema needed).
- [ ] **C3.** `type: z.enum(["dir","file"])` is the ONLY `z.enum` in these
      schemas — it is app-derived. All other string fields are `z.string()` (LL-008).

## API Contract

### GET /api/projects/:name/layer

**Response 200 (layer present, populated):**
```json
{
  "has_layer": true,
  "root_rel": ".claude/project",
  "nodes": [
    {
      "name": "conventions",
      "type": "dir",
      "rel_path": "conventions",
      "size_bytes": null,
      "children": [
        { "name": "typescript.md", "type": "file", "rel_path": "conventions/typescript.md", "size_bytes": 1234 }
      ]
    }
  ],
  "empty": false,
  "truncated": false
}
```

**Response 200 (no layer dir):**
```json
{ "has_layer": false, "root_rel": ".claude/project", "nodes": [], "empty": true, "truncated": false }
```

**Response 404:**
```json
{ "error": { "code": "NOT_FOUND", "message": "Project 'x' is not registered in the vault", "detail": { "name": "x" } } }
```

---

### GET /api/projects/:name/layer/file?path=conventions/typescript.md

**Response 200 (text file):**
```json
{ "rel_path": "conventions/typescript.md", "name": "typescript.md", "content": "# Convention...", "size_bytes": 1234, "truncated": false, "too_large": false, "binary": false }
```

**Response 200 (too large):**
```json
{ "rel_path": "big.bin", "name": "big.bin", "content": null, "size_bytes": 2097152, "truncated": false, "too_large": true, "binary": false }
```

**Response 400:** `{ "error": { "code": "BAD_REQUEST", "message": "Missing 'path' query parameter", "detail": { "rel": "" } } }`

**Response 403:** `{ "error": { "code": "PATH_FORBIDDEN", "message": "Path escapes the layer root", "detail": { "rel": "../etc/passwd" } } }`

**Response 404:** `{ "error": { "code": "NOT_FOUND", "message": "File not found", "detail": { "rel": "missing.md" } } }`

## Technical Notes

- **z.lazy recursion:** TypeScript requires an explicit type annotation when using `z.lazy` for self-referential schemas. Use a named interface (`LayerNodeShape`) and annotate `z.ZodType<LayerNodeShape>` as shown in C1.
- **`truncated` default:** in v1, `truncated` in `LayerFileResponse` is always `false` (we serve whole-file-or-null); the field is reserved for a future partial-content mode.
- **Import paths in tests:** backend tests import from `"../repositories/layerReader.js"` and `"../services/projectLayer.js"` (`.js` extension, ESM). Verified against existing test files (`projectReader.test.ts` line 18, `projectDetail.test.ts` line 22).
- **Tab switching:** `ProjectDetailShell` currently has a static `TabsBar`. S4 replaces it with an interactive variant using `useState<"config" | "layer">("config")`. The other three tabs ("RETRO", "Telemetría", "Agentes") remain inert/disabled.
- **`realpath` on the root:** call `fs.realpath(root)` every request (not once at startup) so a moved/remounted layer root is caught immediately (live-reads-no-stale-cache, fs-and-vault-safety §6).
- **No color literals in frontend:** the Pencil design spec uses `$jade` / `$text-3` / `$surface` / `$border` / `$radius-card` — map directly to CSS custom properties. No hex codes.
