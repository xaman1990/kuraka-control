# REQ-20260622-S3: Project Detail — Config / Overview Tab content

**Parent REQ:** `docs/process/REQ-20260622-S3-project-config-tab.md` ·
**Complexity:** S · **Mode:** combined 1+2 · read-only.

## Contract — `ProjectConfig` (curated, permissive — [LL-008])

Add to `packages/contracts/src/index.ts`, then compose onto `ProjectDetail`:

```ts
/** Curated projection of <project>/kuraka.config.yaml (S3).
 *  Externally-owned values → z.string()/number, ALL nullable. NO z.enum. */
export const ProjectConfig = z.object({
  backend_language: z.string().nullable(),   // stack.backend.language
  backend_framework: z.string().nullable(),  // stack.backend.framework
  frontend_language: z.string().nullable(),  // stack.frontend.language
  frontend_framework: z.string().nullable(), // stack.frontend.framework
  architecture_layers: z.array(z.string()),  // architecture.layers ([] when absent/empty)
  state_mgmt: z.string().nullable(),         // stack.frontend.state_mgmt
  naming_language: z.string().nullable(),    // conventions.naming_language
  max_file_loc: z.number().nullable(),       // conventions.max_file_loc
  max_function_loc: z.number().nullable(),   // conventions.max_function_loc
  default_mode: z.string().nullable(),       // workflow.default_mode
});
export type ProjectConfig = z.infer<typeof ProjectConfig>;

export const ProjectDetail = ProjectSummary.extend({
  drift: Drift,
  config: ProjectConfig.nullable(),          // null = no/unreadable config file
});
```
`config` is `null` (whole-object) only when the file is absent/unreadable/
malformed. When the file parses, individual missing fields are per-field
`null`/`[]` — never crash.

## ConfigCard row mapping (design)

| Row label | Source field(s) | Render |
|---|---|---|
| Stack backend | `backend_language` / `backend_framework` | `"{lang} / {framework}"`; show row if either present |
| Stack frontend | `frontend_language` / `frontend_framework` | `"{lang} / {framework}"`; show row if either present |
| Architecture | `architecture_layers` | join with `" → "`; show row if non-empty |
| Store | `state_mgmt` | verbatim; show row if present |
| Naming | `naming_language` | verbatim; show row if present |
| Limits | `max_file_loc` / `max_function_loc` | `"file {n} · fn {m}"`; show row if either present |
| Workflow | `default_mode` | verbatim; show row if present |

A row is hidden when its source is `null`/empty (never render "null"/blank).

## Acceptance Criteria

### Backend (repository)
- **B1** `readProjectConfig(projectPath: string): Promise<ProjectConfig | null>`
  added to `backend/src/repositories/projectReader.ts`. Reads
  `path.join(projectPath, "kuraka.config.yaml")` with `fs.readFile`, parses with
  `yaml.parse` (NOT JSON).
- **B2** Returns `null` on ENOENT / EACCES / YAML parse error / parsed value not
  a plain object — via `try/catch`, **never throws** (mirror `readLockVersion`).
- **B3** Curates defensively: every section optional. Reads
  `stack?.backend?.language`, `stack?.frontend?.framework`, etc.; missing field
  → `null`. `architecture?.layers` → `[]` when absent/not-an-array.
- **B4** `max_file_loc` / `max_function_loc` returned as `number` when numeric,
  else `null` (do not coerce strings).
- **B5** No new write or subprocess; read-only.

### Backend (service / route)
- **B6** `getProjectDetail` (`services/projectDetail.ts`) adds
  `readProjectConfig(summary.path)` into the existing `Promise.all` and includes
  `config` in the returned `ProjectDetail`.
- **B7** No route change: `GET /api/projects/:name` still returns **200** with
  `config` (object or `null`); absent config never produces 404/500.

### Contract
- **C1** `ProjectConfig` + `ProjectDetail.config` added per the block above; all
  value fields `z.string()`/`z.number()` nullable, layers `z.array(z.string())`.
- **C2** No `z.enum` on any config value (GATE0: `naming_language`,
  `null_syntax`, `default_mode`, `state_mgmt` are open vocabularies).
- **C3** snake_case field names; shared schema is the only type source both sides.

### Frontend
- **F1** `frontend/src/components/ConfigCard.tsx` created: prop
  `config: ProjectConfig | null`; renders the labeled rows per the mapping table,
  hiding any row whose source is `null`/empty. ≤ 300 LOC (`max_frontend_file_loc`).
- **F2** Display mapping (label→value formatting) lives in ConfigCard; any
  reusable display map is exported from there, not copied [LL-009].
- **F3** `ProjectDetailShell.tsx` renders `<ConfigCard config={data.config} />`
  as the Config-tab content, below `<DetailHeader>`. Other tabs stay inert
  (no tab-switching added).

### Empty / Error states
- **E1** `config === null` → ConfigCard shows a first-class empty panel
  ("No `kuraka.config.yaml` in this project") — neutral, NOT an error style
  (mirror S2 `not_pinned`). GATE0: real for `guai-home-marketplace`, `sie_v2`.
- **E2** `config` present but a given row's source absent → that row is hidden;
  the rest render. Never display the literal "null".
- **E3** Detail-page loading/not-found/error states unchanged from S2.
